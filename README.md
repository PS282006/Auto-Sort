# Auto-Sort 🧹
A Python automation script to keep your Downloads folder organized.

## How it Works
Auto-Sort scans your directory and automatically categorizes files into sub-folders based on their file extensions (Images, Documents, Code, etc.).

## Features
- **Zero Dependencies:** Uses standard Python libraries.
- **Customizable:** Easily add more file types.
- **Mac-Native:** Designed for macOS file structures.

## Usage
`python3 autosort.py`
